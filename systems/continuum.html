Your AI forgets everything every night. Mine doesn't.

What it is

Every Claude Code session starts from zero. The architecture you explained on Monday, the bug you traced on Tuesday, the decision you settled on Wednesday: gone by Thursday. You pay for that amnesia twice. Once in tokens, once in your own time re explaining.

Continuum is a memory layer that lives in your project. It captures what each session learned, the decisions, project state, preferences, and dead ends, into structured memory files that the next session reads before it does anything else. Your assistant opens with context instead of questions.

It's the exact system I run Flowity AI on. My sessions pick up mid thought across days and machines, because the memory is plain files in the repo: versioned, reviewable, and editable by you. No database, no server, no vendor.

Continuum is opinionated about what deserves remembering. Not transcripts. Conclusions. Not everything. The things that change how the next session behaves.

What you get
  • A structured memory system: index file plus per project and per preference memory files
  • Session end capture routine that distills what was learned into memory, automatically prompted
  • Session start loading conventions so every conversation opens already briefed
  • Handoff files (BRIDGE / STATUS) for switching between machines, agents, or days
  • Full documentation: how it works, how to prune, how to extend
